# Fake Indian Currency Detection using CNN

A deep learning–based web application that detects **fake and real Indian currency notes** using a **Convolutional Neural Network (CNN)**.  
Users can upload an image of an Indian currency note, and the system predicts whether it is **Fake** or **Real**.

---

## Features

- Upload currency note images
- Real-time prediction (Fake / Real)
- CNN-based image classification
- Simple and user-friendly web interface
- Performance visualization (accuracy and loss)

---

## Technologies Used

- Programming Language: Python
- Framework: Flask
- Deep Learning: TensorFlow, Keras
- Frontend: HTML, CSS
- Libraries: NumPy
- Model: Convolutional Neural Network (CNN)
